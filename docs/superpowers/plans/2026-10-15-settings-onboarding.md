# 设置细化与动画新手引导

用户已批准前一轮六项建议，并要求全部实现，加可跳过、可重播的动画引导；沿用现有紧凑视觉，不新增大量设置。

## 实现分工
- 管理页：安全本地草稿、放弃/保存、记住分类；百分比可直接输入；本地有效结果的设置效果预览；观察进度与可操作的异常状态。
- 动画引导模块：虚构评论演示模块区别、悬停概率、选择任务、遮罩查看、飞入/粒子删除、撤销。第一回打开管理页提示，跳过/完成后不再自动出现，设置页可重播；支持键盘、减少动态效果、关闭时释放动画。动画预览复用模块。
- 主线程：评论临时例外（单条、当前评论区账号、白名单），当前评论预填创建规则；过滤编辑器本地自动预览、草稿；后台权限和保留范围、模型效果预览接口；五语言翻译与整合。

## 约束
不自动启动分析、不真实屏蔽示例、不调用模型做设置预览；API Key 不存草稿。模型/提示词修订后的旧证据不可假装准确预测。例外按登录账号/当前原帖/用户或评论隔离，不能变成全局白名单。创建规则需显式保存，默认遮罩、普通文本匹配。用户内容不执行。不给网页扩展私有存储权限。

## 验证
全部实现后统一检查与构建；核心测试只覆盖例外授权、预览纯读、去重/撤销/草稿敏感信息排除等核心边界，不写 UI 单元测试。保留用户关于测试时机的限制，无发布/提交授权。可视验证以隔离的模拟页面完成；真实 X 测试必须维持禁止屏蔽保护。
