# 默认安静浏览与便捷撤销

目标：在保持现有筛选授权、账号隔离和后台队列的前提下，稳定阅读位置，默认悬停显示评论工具，减少同账号重复分析，并提供当前批次撤销。

1. src/content/content.js、content.css：悬停和键盘聚焦显示工具；不改变占位宽度。鼠标、选择和输入期间延迟删除；不可见评论不播放特效；集中补偿动画和恢复造成的阅读锚点变化。自动滚动遇到用户输入时让步。
2. src/background.js：已入队账号不再进入模型请求；同一账号观察请求串行，并利用本地证据限制短时间重复采样。保留完整上下文、当前规则、白名单和关注校验。
3. 后台为本标签页刚入队的新记录签发短期批次令牌。悬浮层合并提示数量，可信点击撤销只使用令牌，不接受任意记录 ID；重新核对账号、最新记录与其他任务所有权，取消未发送操作，等待已发送操作完成后撤回。撤销持久化排除旧任务、过滤及观察证据，观察账号暂缓一天。
4. 五种语言新增简短撤销提示。无新设置，无新权限，无版本变更或提交。

验证：全部实现后统一语法、资源、本地化和构建检查；遵守用户规则，本轮不运行功能测试或新增 UI 单元测试。最终检查卸载清理、页面切换、过期令牌、跨账号和撤销请求竞争等边界。
